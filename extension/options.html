Auto-login for login.gitam.edu

When the login page opens, the extension fills your User ID and password, reads the CAPTCHA, and presses LOGIN once.

0 = always press LOGIN. 0.5 = leave risky reads to you, so a guess never burns one of the site's 5 attempts.
The password is stored only inside this extension, on this machine only: never synced to a Brave/Google account, never sent anywhere but login.gitam.edu. Extension storage is not encrypted, so don't set this up on a shared computer. After a failed password the login is not retried, and LOGIN is pressed at most twice per tab, so the site's 5-attempt lockout can never be triggered by the extension.
